## O que é Git?
Um sistema de controle de versão para acompanhar o histórico de modificações no código.

## O que é GitHub?
Uma plataforma na nuvem para gerenciar repositórios Git e colaborar em equipe.

## Principais Comandos
- `git clone`: Clona um repositório
- `git status`: Verifica o estado dos arquivos
- `git add`: Adiciona arquivos à área de preparação
- `git commit`: Salva as alterações no histórico
- `git branch`: Cria ou lista ramificações
- `git checkout`: Alterna entre branches
- `git restore`: Desfaz alterações locais
- `git merge`: Une branches diferentes
